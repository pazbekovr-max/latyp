# Random Task Generator

**Латыпова Элина Рафаэлевна:** 

## Описание
Это GUI-приложение на Python для генерации случайных задач. Приложение позволяет добавлять свои задачи, фильтровать историю по категориям (учёба, спорт, работа) и сохранять данные в формате JSON.

## Технологии
- Python 3.x
- Библиотеки: tkinter, random, json
- Система контроля версий: Git
